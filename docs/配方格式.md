# 配方格式速查

完整设计见 mods7die 仓库的
`docs/superpowers/specs/2026-09-08-large-mod-pack-support-design.md`。这里只放"写配方时要用的
字段"和可直接抄的模板。

## 三层结构

| 层 | 文件 | 放什么 |
|---|---|---|
| 系列 | `packs/<id>/pack.jsonc` | 识别规则、安装映射、装完校验、启动要求、可选组件、版本策略 |
| 版本 | `packs/<id>/releases/<版本>.jsonc` | 版本号、适配的游戏版本区间、文件清单（artifact）、网盘镜像 |
| 索引 | `index.json` | 机器生成，别手改 |

**安装逻辑一律写在系列级**。同一系列的新补丁只需要新增一个版本条目；补丁真的改了布局时，
写在该条目自己的 `overrides` 里。

## `pack.jsonc`

```jsonc
{
  "schema_version": 1,
  "id": "my-overhaul",                 // 必须与目录名一致
  "name": "My Overhaul",
  "homepage": "https://example.com",
  "summary": "一句话说明",

  // 怎么认出这个模组（用于结构识别与"登记已装的模组"）
  "detect": {
    // all 必须全部命中；any 至少命中一个
    "all": [
      { "root": "mods", "glob": "**/MyOverhaul.dll" }
    ],
    "any": [
      { "modinfo": { "author": "Someone" } },
      { "root": "mods", "glob": "**/MyOverhaul/ModInfo.xml" }
    ]
  },

  // 从 staging 到游戏目录的映射
  "install": [
    { "id": "bepinex",   "target": "game_root", "mode": "tree",    "from": "BepInEx" },
    { "id": "winhttp",   "target": "game_root", "mode": "file",    "from": "winhttp.dll" },
    { "id": "doorstop",  "target": "game_root", "mode": "overlay", "from": "doorstop_config.ini" },
    { "id": "core",      "target": "mods",      "mode": "tree",    "from": "Mods/MyOverhaul" }
  ],

  // 装完校验：这些路径必须存在，否则报告"安装后校验未通过"
  "expect": [
    { "root": "game_root", "path": "winhttp.dll" },
    { "root": "mods",      "path": "MyOverhaul/MyOverhaul.dll" }
  ],

  "dependencies": [],        // 缺少时告警（不代下载）
  "legacy_conflicts": [],    // 检测到旧残留时告警
  "deletions": [],           // 需要删除的路径（相对 game_root）

  "launch": { "eac": false },  // false = 必须用 7DaysToDie.exe 启动（关 EAC）
  "game_version": { "min": "2.6", "max": "2.6" },   // 兜底条目用的默认区间

  // 版本真值来源与权威顺序（用于体检对账；只比"系列"）
  "version_sources": { "runtime_log": "BepInEx/LogOutput.log" },
  "version_authority": ["runtime_log", "modinfo", "recorded"],

  // 索引里没有这个补丁时是否允许按系列逻辑安装（默认 true）
  "version_policy": { "allow_unlisted_patch": true },

  // 可选组件（汉化、语音包等）：不参与"一个副本一个大型模组"的互斥计数
  "optional_components": [
    {
      "id": "zh-hans",
      "name": "简体中文汉化",
      "detect": { "any": [{ "root": "mods", "glob": "MyOverhaulChinese" }] },
      "install": [
        { "id": "zh", "target": "mods", "mode": "tree", "from": "MyOverhaulChinese" }
      ]
    }
  ]
}
```

`mode` 可选：`tree`（整树复制）、`file`（单文件）、`overlay`（合并进已存在目录，同名覆盖）、
`nested_into`（覆盖进另一个模组内部，需要 `into`）、`delete`（删除，`from` 填要删的相对路径）。
`target` 可选：`game_root`（游戏根目录）、`mods`（`Mods`）、`data`（`Data`）。
**所有目标路径必须落在游戏目录子树内**，执行器会硬校验。

## `releases/<版本>.jsonc`

```jsonc
{
  "schema_version": 1,
  "pack": "my-overhaul",
  "version": "1.2.3",
  "game_version": { "min": "2.6", "max": "2.6" },

  "artifacts": [
    {
      "id": "part1",
      "url": "https://example.com/MyOverhaul-1.2.3-part1.zip",  // 或 "local:文件名"
      "sha256": "…64 位十六进制…",   // 强烈建议填；填了就在解压前硬校验
      "size": 2146584576,             // 可选，仅提示
      "extract": "root",
      "strip_components": 0           // 压缩包多套了一层外壳目录时填 1
    }
  ],

  "mirrors": [
    { "label": "百度网盘", "url": "https://pan.baidu.com/s/…", "password": "abcd", "note": "需自行下载" }
  ]
}
```

`url` 用 `local:<文件名>` 表示"由用户自行下载后提供"——应用会把文件名与配方登记的比对：
同名或"只差版本号"都算合理，完全对不上只警告（整合版改名是常态），但**声明了 `sha256` 就不符即拒绝**。

## 补丁改了布局：`overrides`

```jsonc
"overrides": {
  "component_patches": [{ "id": "core", "from": "Mods/MyOverhaul-2" }],
  "install_add":    [{ "id": "extra", "target": "mods", "mode": "tree", "from": "Mods/Extra" }],
  "install_remove": ["winhttp"],
  "deletions_add":  ["Mods/MyOverhaul/Old.dll"],
  "deletions_remove": [],
  "expect_add":     [{ "root": "mods", "path": "MyOverhaul-2/MyOverhaul.dll" }],
  "expect_remove":  [],
  "optional_components_add": [],
  "optional_components_remove": ["zh-hans"]
}
```

规则：

- **只写差异**，不复制整份配方；没写的字段沿用系列级的值。
- 引用不存在的组件 id / 删除项 / 校验项会**直接报错**（不静默忽略），`mods7pack verify` 会拦住。
- 覆盖之后配方仍必须合法（例如 `nested_into` 必须有 `into`）。
- **不支持**覆盖 `detect` / `launch` / `dependencies`：识别必须在版本未知时就能工作，
  所以识别规则是系列级的。

## 验证清单

提交前跑：

```powershell
cargo run --release --manifest-path ..\mods7die\Cargo.toml -p mods7day --bin mods7pack -- verify .
cargo run --release --manifest-path ..\mods7die\Cargo.toml -p mods7day --bin mods7pack -- index .
```

`verify` 会检查：索引引用的文件存在、配方合法、`overrides` 引用有效、没有未登记的配方文件、
索引是最新的。
